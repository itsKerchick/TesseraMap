# TesseraMap 🛰️

Минималистичный сервис интерактивной спутниковой сегментации местности на базе ансамбля нейросетей YOLO26x и SegFormer-B5.

## Особенности
- **Минималистичный интерфейс** в чёрно-красной эстетике с поддержкой переключения тёмной/светлой темы.
- **Подключение по API MapTiler** с верификацией ключа и ссылкой на руководство (`/maptiler_guide.pdf`).
- **Интерактивная сегментация карты**:
  - Начальная локация: Ростов-на-Дону (zoom 16).
  - Скрытие / включение любых классов (Здания, Дороги, Водоёмы, Растительность и т.д.) без повторного инференса.
  - Наведение курсора на выделенный сектор карты мгновенно определяет и подписывает класс объекта.
  - Настройка прозрачности выделения.
  - Режим сканирования в реальном времени при перемещении карты.
- **Телеметрия в реальном времени**:
  - Серверные метрики: модель GPU, нагрузка VRAM, часы работы, одновременные пользователи.
  - Клиентские метрики: пинг к серверу, IP-адрес.
- **Логирование**:
  - Просмотр логов клиента и сервера.
  - Быстрое копирование последних важных строк в буфер обмена.
  - Скачивание файла логов.

## Запуск
```powershell
# Из папки TesseraMap:
.\run.bat
# или:
..\SegFormer-Benchmark\.venv\Scripts\python.exe server.py
```
После запуска откройте в браузере: `http://127.0.0.1:7861`
