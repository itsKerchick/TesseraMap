# TesseraMap 🛰️ — «Космический детектив»

Интерактивная геоинформационная веб-система для семантической сегментации спутниковых снимков сверхвысокого разрешения на базе ансамбля нейросетей **YOLO26x** и **SegFormer-B5**.

> 📌 **О проекте:**  
> Проект вдохновлён задачей **«Космический детектив» — учим компьютер находить объекты на спутниковых снимках** с образовательной платформы [Сириус.Лето](https://leto.sirius.online).  
> **Цель:** исследовать возможности современных архитектур компьютерного зрения (свёрточных сетей и визуальных трансформеров) в задаче распознавания ключевых классов земной поверхности (здания, дороги, водоёмы, растительность, поля) на реальных спутниковых снимках и предоставить удобный интерактивный веб-инструмент для анализа карты в реальном времени.

---

## 🔬 Исследование и выбор моделей

Подробный отчёт о процессе обучения, тестирования и подбора оптимального баланса моделей находится в файле:  
👉 **[Investigation.docx](Investigation.docx)**

### Основные выводы исследования:
- **YOLO26x-seg (mIoU ~55.9%)**: молниеносная скорость инференса, чёткие границы геометрических объектов (здания, прямые участки дорог), но слабая связность протяжённых природных зон.
- **SegFormer-B5 (mIoU ~61.4%)**: глубокий контекст благодаря механизму внимания (Self-Attention), безупречно выделяет лесные массивы, водоёмы и сложный рельеф, однако даёт слегка сглаженные контуры углов зданий.
- **Ансамбль (Weighted Logits Ensemble, 60% SegFormer + 40% YOLO)**: устраняет недостатки обеих архитектур, формируя наиболее точную и визуально чистую сегментационную карту местности.

## 🏗 Архитектура системы

Проект спроектирован по модульной клиент-серверной архитектуре:

```
  [ Пользователь в браузере / на смартфоне ]
                    │
                    ▼  HTTPS (порт 443)
       ┌─────────────────────────┐
       │   VPS Сервер (Германия) │
       │     vps_server.py       │ ──> Проксирование спутника (без VPN)
       │ Caddy (автоматический SSL)│
       └────────────┬────────────┘
                    ▲
                    │ Исходящий WebSocket-туннель
                    │ wss://tessera.mrkerchick.ru/ws/worker
                    │ (работает через любой NAT / серый IP)
                    ▼
       ┌─────────────────────────┐
       │   Домашний ПК (GPU)     │
       │        worker.py        │
       │ NVIDIA RTX 4060 Ti CUDA │
       │   YOLO26x + SegFormer   │
       └─────────────────────────┘
```

1. **Веб-клиент (SPA, Leaflet, HTML5/CSS3)**:
   - Бруталистский HUD-интерфейс с поддержкой тёмной и светлой тем.
   - Динамическое разбиение карты на тайлы с мягким перекрытием (feathering blending) для устранения стыков.
   - Живая телеметрия (нагрузка GPU, VRAM, пинг, трафик, количество активных пользователей).
   - Полноценная адаптация под мобильные экраны (iOS / Android).
   - Встроенный онлайн-просмотрщик обучающего гайда по MapTiler API ([maptiler_guide.docx](maptiler_guide.docx)).

2. **VPS Gateway (`vps_server.py`)**:
   - Работает 24/7 на легковесном облачном сервере (1 vCPU, 512 MB RAM).
   - Проксирует спутниковые тайлы, позволяя пользователям из РФ открывать карту **без использования VPN**.
   - Управляет очередью задач и пересылает запросы на домашний GPU-сервер через обратный WebSocket-туннель.

3. **ML Worker (`worker.py`)**:
   - Запускается на машине с дискретной видеокартой (NVIDIA RTX 4060 Ti).
   - Не требует публичного IP или проброса портов (NAT Traversal).
   - Мониторит состояние GPU через NVML.

## 🚀 Инструкция по запуску

### Вариант 1. Автономный локальный запуск (Всё в одном)
Подходит для локальной разработки и тестирования на одном ПК с GPU:

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ВАШ_АККАУНТ/TesseraMap.git
   cd TesseraMap
   ```

2. **Установите зависимости:**
   ```bash
   python -m venv .venv
   # Windows:
   .\.venv\Scripts\activate
   # Linux:
   source .venv/bin/activate

   pip install --upgrade pip
   pip install -r requirements.txt
   ```

3. **Запустите сервер:**
   ```powershell
   python server.py
   # или двойным кликом: run.bat
   ```
   Откройте браузер по адресу: `http://127.0.0.1:7861`.

---

### Вариант 2. Раздельный запуск (VPS Gateway + Домашний Worker)

#### А. На сервере (VPS):
Подробный гайд по установке на Debian/Ubuntu и настройке Caddy с авто-SSL описан в **[DEPLOY.md](DEPLOY.md)**.
```bash
# Кратко:
cd /home/sites/TesseraMap
python3 -m venv .venv
.venv/bin/pip install fastapi uvicorn httpx websockets pydantic
# Запуск через systemd / CLI:
tessera start
```

#### Б. На домашнем компьютере с видеокартой:
1. В файле [run_worker.bat](run_worker.bat) укажите адрес вашего сервера и секретный токен:
   ```cmd
   set "VPS_URL=wss://tessera.mrkerchick.ru/ws/worker"
   set "WORKER_SECRET=ваш_секретный_пароль"
   ```
2. Запустите:
   ```cmd
   run_worker.bat
   ```
   После сообщения `=== УСПЕШНО ПОДКЛЮЧЕНО К VPS ===` домашний сервер начнёт принимать запросы на сегментацию от посетителей сайта.

## 📦 Веса моделей (Weights)

Модели сегментации:
- **YOLO26x**: `weights/yolo/best.pt` (~80.7 МБ)
- **SegFormer-B5**: `weights/segformer/model.safetensors` (~338.5 МБ) и `config.json`

Из-за ограничения GitHub на размер файлов (максимум 100 МБ на файл) большие веса размещены в **[GitHub Releases](../../releases)**.

Для автоматической загрузки весов в проект выполните:
```bash
python download_weights.py
```
