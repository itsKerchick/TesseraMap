# TesseraMap 🛰️

Минималистичный сервис интерактивной спутниковой сегментации местности на базе ансамбля нейросетей YOLO и SegFormer-B5.

---

## Архитектура: Клиент (VPS) / Домашний Сервер (Worker)

Проект разделен на две независимые части:
1. **VPS Веб-шлюз (`vps_server.py`)**:
   - Размещается на публичном VPS (например, в Германии) и работает 24/7.
   - Раздает веб-интерфейс (`index.html`), иконки и руководство пользователя.
   - Сайт **всегда доступен пользователям**, даже если домашний компьютер выключен!
   - Не требует видеокарты, CUDA или PyTorch.
2. **Домашний ML-воркер (`worker.py`)**:
   - Работает на вашем домашнем компьютере с видеокартой NVIDIA GeForce RTX 4060 Ti (PyTorch + CUDA).
   - **Не требует белого IP или проброса портов** на роутере: воркер сам подключается к VPS через исходящий WebSocket-туннель (`/ws/worker`).
   - Автоматически переподключается при сбоях сети или включении ПК.
   - Если домашний ПК выключен, сайт сообщает пользователю: *«Сервер не доступен :( Ну...мда. Можете написать мне, тогда я его возможно запущу.»* с возможностью открыть карту в режиме просмотра.
3. **Автономный сервер (`server.py`)**:
   - All-in-one сервер для локальной отладки на одной машине.

Подробная инструкция по настройке и развёртыванию: **[DEPLOY.md](DEPLOY.md)**.

## Быстрый запуск

### 1. Локальное тестирование раздельной архитектуры (VPS Gateway + Worker)
- **Терминал 1 (Веб-шлюз):**
  ```powershell
  .\run_vps.bat
  ```
- **Терминал 2 (Домашний ML-воркер):**
  ```powershell
  .\run_worker.bat
  ```
- Откройте в браузере: `http://127.0.0.1:7861`

### 2. Монолитный локальный запуск (всё в одном)
```powershell
.\run.bat
```

## Особенности интерфейса
- **Минималистичный бруталистский дизайн** в стиле личного портфолио (глубокий чёрный цвет, акцентные красные элементы, аккуратные парящие островки).
- **Начальная точка**: Ростов-на-Дону (zoom 16).
- **Интерактивные слои**:
  - Названия улиц, городов и ориентиров отдельным прозрачным слоем.
  - Наведение курсора на цветовую маску показывает название класса местности.
  - Фильтрация отображаемых классов без повторного расчета.
- **Живая телеметрия**:
  - Модель видеокарты, график нагрузки GPU со спарклайном и детальным просмотром.
  - Счётчики переданного сетевого трафика (↑ / ↓).
  - Пинг и IP клиента.
  - Анимированный индикатор отключения или обрыва связи с домашним сервером.
