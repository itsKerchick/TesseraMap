# Развёртывание TesseraMap: Архитектура Клиент (VPS) / Домашний Сервер (Worker)

Данная архитектура решает задачу:
1. **Сайт доступен 24/7**, даже когда домашний компьютер выключен или спит. Пользователи всегда могут зайти, открыть спутниковую карту, ввести свой MapTiler API ключ, ознакомиться с инструкцией.
2. **Домашний ПК не требует белого IP, статического IP или проброса портов (NAT/CGNAT traversal)**: домашний воркер сам открывает исходящее долгоживущее WebSocket-соединение (`/ws/worker`) к VPS в Германии. Через этот защищённый туннель VPS проксирует запросы на сегментацию и получает телеметрию GPU.

---

## Схема взаимодействия

```
  [ Пользователь в браузере ]
              │  HTTP GET / (Сайт открывается ВСЕГДА)
              ▼
   ┌──────────────────────────────────────────────┐
   │          VPS в Германии (Белый IP)           │
   │  Файл: vps_server.py                         │
   │  • Раздача index.html, favicon, PDF          │
   │  • Проверка ключей MapTiler и геокодинг      │
   │  • WebSocket Gateway: /ws/worker             │
   └──────────────────────┬───────────────────────┘
                          ▲
                          │ Исходящий WebSocket-туннель
                          │ (через любой серый IP / NAT)
                          │ wss://vps.domain.com/ws/worker
                          ▼
   ┌──────────────────────────────────────────────┐
   │        Домашний ПК (Серый IP / NAT)          │
   │  Файл: worker.py                             │
   │  • GPU: NVIDIA GeForce RTX 4060 Ti (CUDA)    │
   │  • PyTorch: SegFormer + YOLO + Ансамбль     │
   │  • Мониторинг NVML (нагрузка GPU, VRAM)      │
   │  • Автоматический реконнект при обрывах      │
   └──────────────────────────────────────────────┘
```

## 1. Развёртывание на VPS в Германии

На VPS **НЕ** нужны видеокарта, CUDA или тяжёлый PyTorch. Достаточно обычного дешёвого сервера (1 vCPU, 512 MB – 1 GB RAM).

### Шаг 1. Файлы для VPS
Скопируйте на VPS следующие файлы из папки `TesseraMap`:
- `vps_server.py`
- `index.html`
- `maptiler_guide.pdf`
- `favicon.ico`, `favicon.png`, `favicon.svg`

### Шаг 2. Установка минимальных зависимостей на VPS
```bash
sudo apt update && sudo apt install -y python3 python3-pip
pip install fastapi uvicorn[standard] httpx websockets pydantic
```

### Шаг 3. Запуск сервера на VPS

#### Вариант А: Быстрый запуск в консоли / tmux / screen:
```bash
export WORKER_SECRET="ваш_секретный_пароль_2026"
export PORT=7861
python3 vps_server.py
```

#### Вариант Б: Как системный сервис systemd (автозапуск 24/7):
Создайте файл `/etc/systemd/system/tesseramap.service`:
```ini
[Unit]
Description=TesseraMap VPS Web Gateway
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/tesseramap
Environment=WORKER_SECRET=ваш_секретный_пароль_2026
Environment=PORT=7861
Environment=HOST=0.0.0.0
ExecStart=/usr/bin/python3 vps_server.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
Активируйте:
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now tesseramap
```

*(Опционально: если на VPS стоит Nginx/Caddy, настройте проксирование на порт `7861`, включая заголовки `Upgrade $http_upgrade` и `Connection "upgrade"` для WebSocket).*

## 2. Запуск домашнего ML-воркера (на вашем ПК)

На домашнем компьютере у вас уже установлены PyTorch, CUDA, SegFormer и YOLO в `.venv`.

1. Откройте файл `run_worker.bat` (или задайте параметры запуска в командной строке):
   ```cmd
   python worker.py --vps "ws://IP_ВАШЕГО_VPS:7861/ws/worker" --token "ваш_секретный_пароль_2026"
   ```
   *(Если на VPS настроен SSL/HTTPS через домен, используйте префикс `wss://`, например: `wss://map.yourdomain.com/ws/worker`)*.

2. Домашний воркер подключится к VPS. В консоли воркера появится:
   ```
   === УСПЕШНО ПОДКЛЮЧЕНО К VPS ===
   Домашний сервер готов принимать запросы на сегментацию от пользователей!
   ```

## 3. Что видит пользователь на сайте?

- **Когда домашний ПК выключен:**
  - Сайт открывается мгновенно, без задержек.
  - Пользователь вводит MapTiler ключ.
  - Статус подключения показывает:
    **«Сервер не доступен :(»**
    *«Ну...мда. Можете написать мне, тогда я его возможно запущу.»*
  - Появляются удобные кнопки:
    - `[Попробовать снова]` — повторить проверку сервера.
    - `[Открыть карту (без сканирования)]` — войти и свободно просматривать спутниковую карту и надписи улиц/городов.
  - На карте индикатор сверху справа мягко показывает: **«Сервер оффлайн»**.
- **Когда вы включаете домашний ПК и запускаете воркер:**
  - Через 1 секунду WebSocket туннель соединяется.
  - Индикатор «Сервер оффлайн» автоматически гаснет.
  - Кнопка **«Сканировать»** становится активной.
  - Начинает передаваться живая телеметрия вашей видеокарты RTX 4060 Ti, VRAM и нагрузка с графиком!
