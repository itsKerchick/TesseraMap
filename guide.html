MapTiler API ключ гайд

Пошаговое руководство по созданию бесплатного API ключа для спутниковых карт MapTiler. Ключ создаётся бесплатно за 1 минуту и позволяет загружать детальные спутниковые снимки в TesseraMap.

1
Регистрация аккаунта

Идём сюда: https://cloud.maptiler.com/ и создаём аккаунт через гугл/почту:

2
Вход в панель управления

Когда зарегались/вошли нас перебрасывает сюда: https://cloud.maptiler.com/maps/ (если не перебросило – зайдите сами):

3
Переход в раздел API Keys

Тут нажимаете крестик и переходите в вкладку “API Keys”:

4
Создание нового ключа

На странице API Keys нажимаете “NEW KEY”:

5
Имя ключа и подтверждение

Вписываете любое имя ключа и нажимаете “CREATE”:

6
Копирование ключа

Копируете ключ. В моём случае это: LRNp35SW67SP8U5pxp85:

7
Вставка ключа в TesseraMap

Возвращаетесь назад (https://tessera.mrkerchick.ru) и вводите этот ключ в поле ввода и нажимаете “Подключиться”:
